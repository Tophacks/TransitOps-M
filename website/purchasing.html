02 / ACCEPTANCE GATES

Each stage earns
the next purchase.

The larger two-bay depot is a CAD concept. Start with one working route and one bay; expand after measured results.

01

Select the first vehicle

Verify dimensions, practical turning radius, charging arrangement, tools and delivered price. Reserve an unobstructed test-loop footprint.

RESEARCHING
02

Measure movement and stopping

After acquisition, target 20 consecutive tracked laps and record 20 stopping cycles. Use the measured swept path and stopping spread to set clearances.

PLANNED
03

Connect one instrumented bay

Validate sensor feedback, driver electronics and power-loss behavior. The simulation API is not a physical vehicle controller.

PLANNED
04

Scale the proven design

Revise depot geometry, then consider further buses, switches and scenery. Automated charging requires its own verified design.
