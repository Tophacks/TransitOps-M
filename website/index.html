OUR MISSION / WHY WE BUILD

Engineering progress.
Public inspiration.

TransitOps-M develops intelligent miniature transportation systems to advance engineering research, demonstrate emerging technologies, and inspire the next generation of engineers.

We bring together experimental fleet-control software, physical prototypes, and accessible public demonstrations—creating a place where ideas can be tested, seen, and understood.

01 / THE VISION

More than a
miniature city.

TransitOps-M is developing a physical-scale testbed to investigate the coordination problems behind reliable transit: delayed vehicles, depot capacity, charging, and safe replacement dispatch.

DEVELOPMENT / 23 OCTOBER 2026

One bus first.
Evidence before scale.

The next build starts with a guided test vehicle and one instrumented stop. Hardware selection is under review; no physical fleet has been validated.

SOFTWARE / UPDATED

A more robust API

Malformed commands return errors, and concurrent requests update the simulator in sequence. Automated HTTP regression tests cover the changes.

HARDWARE / RESEARCH

Two vehicle candidates

An assembled MB O405 starter set and a Citaro alternative are being compared. Delivered cost, dimensions and charging equipment still need confirmation.

NEXT / VALIDATION

Prove the test loop

Measure turning clearance and stopping repeatability before ordering permanent roads, depot prints or additional buses.
